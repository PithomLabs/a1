# Commercial Services Model (no code in MVP)

**Status:** Phase 1 design gate candidate · **Date:** 2026-11-08

Open core (MIT): kernel, SDK, CLI, API, console, reference module, examples,
docs. Paid engagements: custom module development, integration adapters,
business-rule formalization, production-support simulation builds, custom
scenario/assessment libraries, private deployment and maintenance.

Guardrails: no billing or license-server code in the MVP; core stays fully
usable without any paid dependency; customer work happens in separate repos
with explicit IP terms (see `private-module-isolation.md` and
`licensing-and-ip-boundaries.md`); the public roadmap never gates community
features behind services. First commercial proposition: "we build a realistic
test environment for your business workflows."
